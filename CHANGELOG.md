\# Changelog



Todos los cambios notables en este proyecto serán documentados en este archivo.



\## \[v0.1.0] - 2026-01-20

\### Added (Añadido)

\- \*\*Estructura del Proyecto:\*\* Inicialización del repositorio con estructura base para Spring Boot (Backend) y Angular (Frontend).

\- \*\*Documentación:\*\* Creación de archivos `README.md`, `CONTRIBUTING.md` y carpeta `docs/`.

\- \*\*Gestión de Proyecto:\*\* Configuración de plantillas para Issues y Pull Requests en `.github/`.

\- \*\*Integración Continua:\*\* Configuración básica de flujos de trabajo (Workflows).

\- \*\*Evidencias:\*\* Documento de trazabilidad del Sprint 1 (`docs/sprint1-evidencias.md`).

- **Gestión (PO):** Creación del Product Backlog inicial con Historias de Usuario (S1-US01 a S1-US12) y definición del Milestone "Sprint 1".
- **Gobernanza (SM):** Definición de estrategia de ramas (Gitflow), convención de commits y reglas de contribución (`CONTRIBUTING.md`).
- **Infraestructura (Dev A):** Configuración de plantillas de GitHub (`.github/`) para Issues (Bug/Feature/Tech) y Pull Requests.
- **Documentación (Dev B):** Generación de tablas de evidencias y trazabilidad del Sprint 1.
- **Flujo de Trabajo:** Documentación del flujo colaborativo en `docs/flujo-trabajo.md`.

### Fixed (Corregido)
- **Conflictos (Dev C):** Resolución de conflictos de fusión simulados en la documentación del flujo de trabajo, asegurando la integridad del historial.

### Security (Seguridad)
- **Branch Protection (SM):** Activación de reglas de protección para la rama `main` (requiere PR y revisión obligatoria).
